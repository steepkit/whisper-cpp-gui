## Physical Mac validation waiver

No physical Apple Silicon Mac was available for v0.1.1. The physical Apple
Silicon validation procedure documented in ADR 0016 remains unexecuted. This
includes real media, both presets, VAD, txt/srt/vtt output, progress and logs,
cancellation, browser downloads, bootstrap recovery, 8 GB large-v3 memory use,
Downloads permissions, automatic browser launch, and real model download timing
and SHA256 verification.

GitHub-hosted macOS build/startup and Homebrew source-install CI passed only as
packaging checks. They do not establish physical GUI or workload compatibility.
Please report failures without attaching media, transcripts, model files,
tokens, or private paths.

## Changes

- Preserve authentication and the active job across same-tab page reloads by
  using `sessionStorage`; tokens are still removed from the URL and are never
  stored in `localStorage` or cookies.
- Reconnect to an active transcription after a reload, with bounded retry for
  transient lookup and SSE failures.
- Clear stale authentication or job state after confirmed 401/404 responses.
- Preserve a valid saved same-tab session when a malformed token fragment is
  opened.

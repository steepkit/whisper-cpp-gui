# 手順書・README 検証依頼(M4-4)

あなたは、研究室に新しく入った非エンジニアの Mac ユーザーです。同時に、技術文書の穴を見つけるのが得意なテクニカルライターでもあります。以下の導入手順書を読み、「これだけ読んで本当に導入できるか」を厳しく検証してください。

## 検証の観点

1. **前提の欠落**: Homebrew 未導入、Xcode CLT 未導入、Apple Silicon でない、ネットワーク制限下 — 手順が黙って前提していないか
2. **順序と分岐**: `brew tap` → `install` → 起動 → モデル DL → 文字起こし の流れに飛躍がないか。失敗時にどうするかが書かれているか
3. **用語**: 非エンジニアが詰まる用語(ターミナル、tap、パス)に説明があるか
4. **不整合**: 手順書のコマンド・パス・画面名が、実際の実装(API / UI 文字列 / 出力先)と一致しているか
5. **スクショ指定**: 「スクショ位置指定」が実際の画面遷移と対応しているか

## 出力形式

```
## Blocking gaps(これがあると導入できない)
- <箇所> : <何が欠けているか> / <どう直すべきか>

## Confusing points(詰まりそう)
- <箇所> : <なぜ詰まるか>

## Inconsistencies with implementation
- <手順書の記述> vs <実装/UI の実際>

## Good
- <わかりやすい点(残すべき)>
```

英語 README(開発者向け)と日本語導入手順(研究室向け)で読者が違うことを踏まえて評価してください。
